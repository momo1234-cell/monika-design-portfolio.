# Monika Zhorzholiani — Visual Design Portfolio

A responsive React JSX + Vite portfolio featuring brand identity, packaging, posters, book design, and illustration.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL displayed in the terminal.

## Production build

```bash
npm run build
```

Contact details and biography can be edited in `src/main.jsx`. Project images are in `public/images`.
